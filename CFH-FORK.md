# CFH Share

CFH Share is an independent fork of LocalSend 1.18.2, an open-source app for transferring files between devices. CFH changes the application title and navigation branding, asks for confirmation before adding dropped folders, rejects malformed token structures, updates WebRTC, and uses AWS-LC for RSA identity generation and verification.
