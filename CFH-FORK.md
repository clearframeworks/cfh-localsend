# CFH Share

CFH Share is an experimental fork of LocalSend 1.18.2, an open-source app for transferring files between devices on a local network. This fork changes the application title and navigation branding and asks for confirmation before adding dropped folders. It has not been released as a CFH installer or independently security audited.

Upstream: https://github.com/localsend/localsend
Upstream version: v1.18.2 (af0416be50770a97760f7070684bc667b759a15c)
